### What I build

**Fieldbook** is a web application I designed and built to run a forward-deployed engineering and solutions-architecture organization as a system of record. Each engagement is tied to the production outcome it promised, the evidence that proves it, its cost and what it left behind. It has stage exit gates, a milestone ladder that will not advance without linked evidence, capacity and staffing, field requests with duplicate detection and a named merge-back owner, reusable assets and plays, handoffs, and rule-based weekly status drafting and evidence auditing. Vite, React 19, Tailwind, shadcn/ui, Hono on Node, Postgres and Drizzle. MVP; demo on request.
